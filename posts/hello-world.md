이 블로그는 **프레임워크 없이** 순수 HTML, CSS, JavaScript만으로 만들어졌습니다.

## 지원하는 기능

- 마크다운 → HTML 변환
- 다크 모드 지원
- 모바일 반응형 레이아웃
- 코드 블록 문법 강조

간단한 *기울임*과 **굵게** 표시도 가능하고, `인라인 코드`도 지원합니다.
