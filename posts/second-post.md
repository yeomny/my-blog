# 코드 블록 예제

이 블로그의 코드 블록은 외부 라이브러리 없이 직접 구현한 문법 강조를 사용합니다.

## JavaScript 예제

```javascript
function greet(name) {
  const message = `Hello, ${name}!`;
  console.log(message);
  return message;
}

greet("World");
```

## Python 예제

```python
def greet(name):
    message = f"Hello, {name}!"
    print(message)
    return message

greet("World")
```
