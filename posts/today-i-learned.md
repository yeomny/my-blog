# 오늘배운것

클로드 코드로 이 블로그를 만들어보면서, 세 언어가 각자 어떤 역할을 맡는지 명확히 구분해서 이해하게 되었다.

## HTML — 구조와 뼈대

HTML은 페이지에 어떤 요소가 존재하는지를 정의한다. 예를 들어 다크모드 버튼(`<button id="theme-toggle">`)이나 게시물 목록이 들어갈 `<div id="post-list">` 같은 자리를 마련해두는 역할이다. HTML 자체는 "무엇이 있는지"만 정하고, 그것이 어떻게 보이고 어떻게 동작할지는 관여하지 않는다.

## CSS — 스타일과 표현

CSS는 그 요소들을 실제로 어떻게 보여줄지 담당한다. 예를 들어 `[data-theme="dark"]` 같은 속성 선택자로 다크모드일 때의 배경색과 글자색을 미리 정의해두면, JavaScript가 `data-theme` 속성값만 바꿔줘도 화면 전체의 색이 바뀐다. 즉 JS는 상태만 바꾸고, 실제 시각적 전환은 CSS가 담당하는 구조다.

## JavaScript — 동작과 상태 관리

JavaScript는 사용자 상호작용에 반응해서 상태를 바꾸고 DOM을 조작하는 역할을 한다. 이 블로그에서는 대략 이런 흐름으로 동작한다.

- `theme.js`: 버튼 클릭을 감지해 `localStorage`에 테마를 저장하고, `<html>` 태그의 `data-theme` 속성을 바꿔 다크모드를 전환한다.
- `list.js`: `posts/index.json`을 읽어 마크다운 파일 목록을 가져오고, 프론트매터를 파싱해 목록 화면을 렌더링한다.
- `markdown.js`: 마크다운 문법을 실제 HTML로 변환해 게시물 본문을 그려준다.

## 정리

한 문장으로 요약하면, **HTML은 무엇이 있는지, CSS는 어떻게 보이는지, JavaScript는 언제 무엇이 바뀌는지**를 담당한다. 세 가지가 서로 역할을 침범하지 않고 느슨하게 연결되어 있어야 코드를 이해하고 수정하기가 훨씬 쉬워진다는 것을 이번에 체감했다.
